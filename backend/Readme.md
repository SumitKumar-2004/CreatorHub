# 🎬 CreatorHub Backend

A backend-focused YouTube-inspired video streaming platform built using **Node.js**, **Express.js**, and **MongoDB**.  
CreatorHub Backend provides scalable REST APIs for authentication, video management, likes, comments, subscriptions, and user interactions.

---

## 🚀 Features

- 🔐 JWT Authentication & Authorization
- 👤 User Registration & Login
- 🎥 Video Upload & Management
- 👍 Like & Dislike System
- 💬 Comment System
- 📺 Subscribe / Unsubscribe Functionality
- 📂 RESTful API Architecture
- ☁️ Cloud Media Storage Support
- ⚡ Scalable Backend Folder Structure
- 🛡️ Middleware-based Error Handling
- 📦 MongoDB Database Integration

---
